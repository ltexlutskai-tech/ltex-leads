# L-TEX CRM — Apps Script

Код Google Apps Script, який обслуговує CRM-таблицю L-TEX (Viber-бот, ліди з Gmail,
синхронізація з таблицями менеджерів, щоденний звіт).

Файл: [`ltex-crm.gs`](./ltex-crm.gs) — версія **v6.5**.

---

## v6.5 — колонки для повторного обдзвону бази

Додано дві нові колонки **в кінець** головної таблиці та таблиці кожного менеджера.
Наявні колонки й дані не зсуваються.

| Колонка | Головна таблиця | Файл менеджера | Тип |
|---|---|---|---|
| **Оновлений статус** | R (18) | Q (17) | випадаючий список: `Карточка клієнта` / `без змін` / `вилучити` |
| **Коментар (результат розмови), НПТ (не піднімає трубку)** | S (19) | R (18) | вільний текст |

Обидві колонки синхронізуються **в обидві сторони**:
менеджер заповнює у своєму файлі → значення потрапляє в головну таблицю
(через тригер `onManagerEdit`), і навпаки — правка в головній летить до менеджера.

Захист від затирання: якщо в головній таблиці ці клітинки порожні, повторна
синхронізація **не стирає** те, що вже ввів менеджер.

## Як застосувати

1. Відкрийте CRM-таблицю → **Розширення → Apps Script**.
2. Замініть вміст файлу з CRM-кодом на `ltex-crm.gs`.
   Скрипт звітів (`📊 L-TEX Звіти`, `rebuildAll`, `CFG`…) — окремий файл, його не чіпаємо.
3. Збережіть і запустіть **один раз** з редактора:

   ```
   addUpdatedStatusColumns()
   ```

   Функція:
   - додає колонку `F` в аркуш «Довідники» зі списком значень нового статусу;
   - додає заголовки + випадаючий список у головну таблицю (R, S);
   - те саме в кожному файлі менеджера (Q, R);
   - розтягує об'єднану «шапку» файлів менеджерів на нову ширину.

   Функцію **безпечно запускати повторно** — вона нічого не дублює.

4. Якщо тригери синхронізації ще не встановлені — запустіть:

   ```
   installManagerSyncTriggers()
   ```

5. (Опційно) Перенести вже заповнені менеджерами значення в головну:

   ```
   backfillStatusesFromManagers()
   ```

## Керування списком статусів

Значення випадаючого списку беруться з колонки **F** аркуша «Довідники».
Якщо колонка порожня — використовується список за замовчуванням
(`Карточка клієнта`, `без змін`, `вилучити`).

Додати значення можна:

- вручну в «Довідники», колонка F, потім `syncDictionaryAll()`;
- або через Viber-бота (тільки адмін):

  ```
  /довідник
  Тип: оновлений статус
  Значення: передзвонити пізніше
  ```

## Що ще змінилось у v6.5 (технічно)

- `COL` — додано `NEW_STATUS: 18`, `NEW_COMMENT: 19`.
- `setupManagerFile()` / `fixManagerColumns()` — 16 → 18 колонок у файлах менеджерів.
- `syncToManager()` — маппінг 19 → 18 колонок + збереження введеного менеджером.
- `handleSyncFromManager()` — маппінг нових колонок назад у головну.
- `onManagerEdit()` — читає 18 колонок замість 16.
- `backfillStatusesFromManagers()` — переносить і нові колонки.
- `parseAndSave()` / `saveEmailLead()` — новий рядок має 19 колонок.
- `syncDictionary()` / `syncDictionaryAll()` — валідація нового статусу.
- Перевірка номера в боті показує «Оновлений статус» разом з іншими даними.

> ⚠️ Аркуш звітів `📋 Реєстр` (скрипт «L-TEX Звіти») нові колонки поки не збирає —
> якщо потрібно бачити їх у звітах/зведеній таблиці, це окрема зміна.
