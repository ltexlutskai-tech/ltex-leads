# Apps Script бота L-TEX CRM

`ltex-crm.gs` — повний код скрипта, який стоїть у Google Apps Script
(Viber-бот + синхронізація головної таблиці з файлами менеджерів).
Файл тримається тут як єдина версія правди: правки спочатку сюди,
потім копіювати в редактор Apps Script.

## v6.8 — статуси клієнта з 1С у відповіді бота

У блок «🏭 Знайдено в базі 1С» додано два рядки — «Статус» і «Оп статус»
(колонки **H** та **I** аркуша 1С).

Було:

```
🏭 Знайдено в базі 1С:
Код: 5268
ПІБ: Богачек Тетяна
Агент: Дунас Богдан
Дата: 26.05.2026
```

Стало:

```
🏭 Знайдено в базі 1С:
Код: 5268
ПІБ: Богачек Тетяна
Агент: Дунас Богдан
Дата: 26.05.2026
Статус: Потенційний
Оп статус: Неактивний
```

### Що змінено в коді

| Місце | Зміна |
|---|---|
| `ONS_COL` | додано `STATUS:8`, `OP_STATUS:9` |
| `ONS_HDR_STATUS`, `ONS_HDR_OP_STATUS` | нові константи — заголовки для пошуку колонок |
| `check1CByPhone()` | читає обидві колонки і повертає `status` та `opStatus` |
| `findOnsCol_()` | нова — шукає колонку за заголовком у рядку 1 |
| `onsCell_()` | нова — значення клітинки, порожнє → `—` |
| автоперевірка номера (`doPost`) | два нові рядки у блоці 1С |
| команда `/1с` | два нові рядки у відповіді |
| `parseAndSave()` | статуси в попередженні про дубль і в сповіщенні агенту |

### Чому пошук за заголовком

Номери колонок H/I зашиті лише як значення за замовчуванням. При кожному
виклику скрипт читає рядок 1 аркуша 1С і шукає заголовки «Статус» та
«Оп статус» (також «Оп. статус», «Операційний статус», «Оп-статус»).
Якщо колонки в вивантаженні з 1С посунуться — бот далі показуватиме
правильні значення; якщо заголовків немає взагалі — впаде на H та I.

Порожня клітинка виводиться як `—`, так само як «Оновлений статус» у
блоці CRM.

### Як застосувати

1. Відкрити проєкт Apps Script (той, що прив'язаний до головної таблиці).
2. Замінити код на вміст `ltex-crm.gs`, зберегти.
3. **Deploy → Manage deployments → Edit → New version → Deploy**
   (без нового деплою вебхук Viber і далі викликає стару версію).
4. Перевірка: запустити `test1CStatuses()` з редактора — у Logger має
   з'явитись «Статус: …» та «Оп статус: …». Або просто надіслати боту
   номер клієнта, який є в 1С.

Ключі (`VIBER_TOKEN`, `ANTHROPIC_KEY`, `ONS_FILE_ID`, `LTEX_CRM_URL`,
`LTEX_CRM_SECRET`) лежать у Script Properties і в репозиторії їх немає.
